BIRTHDAY WEBSITE

Files:
- index.html       = Home page
- memories.html    = Memories/photo gallery page
- surprise.html    = Surprise/gift page
- style.css        = Complete design + balloon/floating animations
- script.js        = Gift click + confetti + floating particles
- photos/          = Put your own photos here

PHOTO NAMES:
photos/main.jpg
photos/photo1.jpg ... photos/photo9.jpg

HOW TO RUN:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser (or use Live Server).
4. Replace the images inside the photos folder with your own photos, keeping the same filenames.

The pages are already linked:
Home -> Memories -> Surprise.
